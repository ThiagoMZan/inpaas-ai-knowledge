# Documentos operacionais

Cada arquivo desta pasta descreve um contrato ou procedimento reutilizável da
plataforma inPaaS. Leia apenas os documentos aplicáveis à tarefa, conforme a
matriz em [`../AGENTS.md`](../AGENTS.md), mas leia cada documento selecionado
integralmente antes de agir.

Ao corrigir ou descobrir um comportamento reutilizável, atualize o documento
mais específico existente e registre mudanças de contrato no
[`../CHANGELOG.md`](../CHANGELOG.md). Não duplique regras entre documentos;
use links para relacionar assuntos. Regras de negócio e dados de clientes
pertencem aos repositórios dos respectivos projetos.
