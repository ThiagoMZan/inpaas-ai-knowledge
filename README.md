# inPaaS AI Knowledge

Base de conhecimento operacional compartilhada pelos projetos inPaaS. Os
documentos orientam agentes em tempo de execução; eles não constituem
treinamento ou ajuste do modelo.

## Uso

Clone este repositório ao lado de `inpaas-dev-kit` e adicione ambos ao
workspace do VS Code. O `AGENTS.md` do kit direciona agentes para esta base.

Antes de atuar, leia o `AGENTS.md` e os documentos de `docs/` relacionados à
tarefa. Cada projeto continua responsável por seu próprio `AGENTS.md`, com
regras e decisões exclusivamente locais.

## Contribuições

Atualize a documentação quando confirmar uma regra reutilizável da plataforma.
Não registre dados de clientes, segredos, URLs de ambiente ou decisões de
negócio específicas. Mudanças que afetem contratos ou fluxos de trabalho devem
incluir uma entrada no `CHANGELOG.md`.
